# Changelog

## [Unreleased]

### Added
- TypeScript/JavaScript package (`js/`, npm `schema-compat`): the same API in camelCase
  (`checkSchema`, `transformSchema`, `checkTools`, `transformTools`, `restoreArguments`,
  `nameIsValid`, `sanitizeName`) and CLI. Zero dependencies, ESM + CommonJS + types.
  Verified against a parity corpus generated by the Python package (3,000 schema cases,
  the 149 GitHub MCP tools, tool-shape edge cases and names): identical output, messages
  included.

### Fixed
- Crashes on non-string `format`/`$ref` values and non-string `required` entries.
- Tool and parameter names with a trailing newline were accepted (`re.match` with `$`).
- A root `"type": null` was not replaced by `"object"`.

## [0.1.0] – 2026-11-22

First release.

- `check_schema` / `transform_schema` for five targets: `anthropic`, `anthropic-strict`,
  `openai`, `openai-strict`, `gemini`.
- `check_tools` / `transform_tools` for MCP, Anthropic, OpenAI (Chat and Responses) and Gemini
  tool shapes: name rules with a name map back, duplicate names, missing schemas, Anthropic's
  per-request strict limits, Gemini tools without arguments.
- `restore_arguments`: undo stringified Gemini enum/const values and OpenAI-strict nulls.
- `schema-compat check` / `schema-compat fix` CLI (text, JSON and GitHub annotation output) and
  a pre-commit hook.
- Verified against a hand-written case corpus, the providers' own SDK code (`google-genai`
  `types.Schema`, `openai-agents` strict conversion) and randomised schemas.
